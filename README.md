# CSV Dashboard POC

Next.js + React + TypeScript + Tailwind starter with a mocked Chart.js line chart.

## Run locally

1. Install Node.js 20+
2. Install deps:

```bash
npm install
```

3. Start dev server:

```bash
npm run dev
```

Open http://localhost:3000

## Next step

Replace the mocked data in `src/components/mock-dashboard-chart.tsx` with data parsed from your local CSV file.
